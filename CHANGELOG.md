## [0.1.0] - 2026-02-20

### Added
- Initial `rustycolour` desktop app with `eframe/egui` interface.
- Palette generation across classical and uncommon colour theory methods.
- Seed colour picker, live preview updates, swatch export and copy helpers.
- Import and export support for HEX/RGB/HSL/OKLCH, GPL, ASE, CSS, and JSON.
- Contrast tooling with WCAG/APCA and colour vision deficiency simulation.
- Method/session preset persistence and reusable sample palettes.
- Workspace CI and release automation for Linux and Windows artifacts.
