# Contributing

## Workflow

1. Create or update work on a feature branch from `dev`.
2. Keep changes scoped and documented.
3. Run formatting, linting, and tests before opening a PR.

## Standards

- Prefer explicit, testable APIs in `rustycolour-core`.
- Keep GUI code in `rustycolour-app`; avoid algorithm logic in UI layers.
- Document new generation models in `docs/theory/` with references.

## Pull Requests

- Include a short problem statement and approach.
- Include before/after behavior notes and test coverage.
- Add screenshots for GUI updates when relevant.
